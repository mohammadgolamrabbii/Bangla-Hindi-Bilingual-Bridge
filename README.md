An open-source **Bangla ↔ Hindi ↔ English Parallel Lexicon & Cognate Bridge** constructed by cross-matching **495,209 verified Bangla words** against **411,241 verified Hindi words** using phonological Devanagari-to-Bengali orthographic & nasal-assimilation mapping (`ं` → `ঙ্ / ঞ্ / ণ্ / ন্ / ম্ / ং`).

👉 **Live Trilingual Web Explorer:** [https://mohammadgolamrabbii.github.io/Bangla-Hindi-Bilingual-Bridge/](https://mohammadgolamrabbii.github.io/Bangla-Hindi-Bilingual-Bridge/)

---

## 📊 Verified Dataset Metrics

| Metric | Count | Details |
| :--- | :--- | :--- |
| **Total Parallel Cognate Pairs** | **41,904** | Clean `Bangla ↔ Hindi` TSV pairs across full corpora |
| **Rich Bilingual Lexicon Pairs** | **20,243** | Parallel pairs enriched with definitions, POS & synonyms |
| **Both-Side Rich Verified** | **9,637** | Verified present in both Bangla & Hindi rich dictionaries |
| **With English Glosses** | **9,585** | Full trilingual `BN ↔ HI ↔ EN` entries |
| **Web Explorer Chunks** | **43** | Zero-backend letter chunks (`dist/chunks/`) |
