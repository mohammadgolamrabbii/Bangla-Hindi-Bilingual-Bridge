# 🤝 Contributing to Bangla-Hindi Bilingual Bridge

Contributions to expand or refine the Bangla ↔ Hindi ↔ English parallel cognate bridge are warmly welcomed!

1. Run `node scripts/build_bridge.js` after updating either upstream archive.
2. Verify integrity before committing:
   ```bash
   node scripts/validate_bridge.js
   ```
3. Keep all entries aligned with `schema/bridge.schema.json`.
